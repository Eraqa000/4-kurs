# Чек-лист WCAG 2.1 AA

Статусы: **Авто** — проверено тестом или Lighthouse; **Браузер** — проверено вручную в Chrome
(12.10.2026); **Ручное** — нужна проверка со screen reader или людьми; **Н/п** — неприменимо.

| Критерий | Что сделано | Статус |
|---|---|---|
| 1.1.1 Нетекстовое содержимое | У картинки `alt` = краткое описание, оба уровня описания текстом рядом; миниатюры в списке декоративные (`alt=""`) | Авто; качество описаний — Ручное |
| 1.2.1 Только аудио | Аудио описания дублируется текстом на странице и в `description.txt` | Н/п (текстовая альтернатива есть) |
| 1.3.1 Информация и связи | Landmarks, заголовки h1–h3, `label` у всех полей, списки | Авто (axe, jsx-a11y) |
| 1.3.2 Последовательность | Порядок в DOM = визуальный порядок | Ручное |
| 1.3.3 Сенсорные характеристики | Инструкции не опираются на цвет или форму; «слева/справа» учат по тексту | Ручное |
| 1.3.4 Ориентация | Ограничений нет | Н/п |
| 1.3.5 Назначение полей | Персональных данных не вводится | Н/п |
| 1.4.1 Цвет | Текущий раздел отмечен рамкой и подчёркиванием, не только цветом | Авто+Браузер |
| 1.4.2 Управление звуком | Речь можно поставить на паузу и остановить по `Esc`, отключить в настройках | Авто (тесты) |
| 1.4.3 Контраст текста 4.5:1 | Палитра проверена тестом в обеих темах | Авто |
| 1.4.4 Изменение размера текста | Шрифт 100–200% в настройках; при 200% нет потери содержимого | Браузер |
| 1.4.5 Изображения текста | Не используются | Н/п |
| 1.4.10 Reflow | 320px при шрифте 200%: нет горизонтальной прокрутки (6 страниц, 2 темы) | Браузер |
| 1.4.11 Контраст элементов 3:1 | Рамки, акцент, контур фокуса проверены тестом | Авто |
| 1.4.12 Интервалы текста | Не проверялось | Ручное |
| 1.4.13 Содержимое при наведении | Подсказок при наведении нет | Н/п |
| 2.1.1 Клавиатура | Весь основной сценарий проходится клавиатурой и текстовыми командами | Авто (тесты) |
| 2.1.2 Нет ловушки фокуса | Модальное окно удерживает фокус, закрывается `Esc`, фокус возвращается | Авто |
| 2.1.4 Одиночные клавиши | `R`, `V`, `?`, цифры в уроках отключаются в настройках | Авто |
| 2.2.1 Тайминги | Ограничений по времени нет | Н/п |
| 2.2.2 Пауза, стоп | Мигающего и движущегося содержимого нет | Н/п |
| 2.3.1 Вспышки | Нет | Н/п |
| 2.4.1 Обход блоков | Ссылка «Перейти к содержимому» первая в порядке фокуса | Авто |
| 2.4.2 Заголовок страницы | `document.title` меняется на каждой странице | Авто (RouteFocus) |
| 2.4.3 Порядок фокуса | При смене страницы фокус на h1, в шаге урока на заголовок шага | Авто; Ручное |
| 2.4.4 Назначение ссылки | Ссылки по тексту понятны (в списке уроков — номер, название, статус) | Ручное |
| 2.4.5 Несколько способов | Меню, хоткеи `Alt+1…4`, голосовые команды, поиск в галерее | Ручное |
| 2.4.6 Заголовки и подписи | Описательные | Ручное |
| 2.4.7 Видимый фокус | Контур 4px, отступ 3px, контраст ≥ 3:1 | Авто+Браузер |
| 2.5.1 Жесты | Только клики | Н/п |
| 2.5.2 Отмена указателя | Стандартные кнопки | Н/п |
| 2.5.3 Подпись в имени | Видимый текст входит в имя кнопки | Авто (axe) |
| 2.5.4 Движение устройства | Не используется | Н/п |
| 3.1.1 Язык страницы | `<html lang>` переключается kk/ru | Авто |
| 3.1.2 Язык частей | Содержимое одного языка; запрос ребёнка может быть на другом | Ручное |
| 3.2.1 При фокусе | Контекст не меняется | Ручное |
| 3.2.2 При вводе | Выбор языка применяется сразу (см. риск 1 в отчёте) | **Риск** |
| 3.3.1 Ошибки | Ошибки текстом и через live-регион, с языком пользователя | Авто (тесты) |
| 3.3.2 Подписи и инструкции | У всех полей есть `label` | Авто |
| 3.3.3 Подсказки по исправлению | Модерация, лимит и ошибки говорят, что сделать | Авто |
| 3.3.4 Предотвращение ошибок | Удаление требует подтверждения, фокус на «Нет» | Авто |
| 4.1.2 Имя, роль, значение | `aria-pressed`, `aria-current`, `role=dialog`, подписи | Авто (axe) |
| 4.1.3 Сообщения о статусе | Глобальные `aria-live` области polite и assertive | Авто |

Размер целей касания 44px (рекомендация плана, критерий 2.5.5 уровня AAA): проверено в Chrome
на 1280px и 320px при 200%.
